§ 1 · 과학적 배경

ECM이란, 그리고 왜 구조가 중요한가

생물 조직은 세포만으로 이뤄진 게 아니에요. 세포들 사이 공간을 채우는 세포외기질(ECM, Extracellular Matrix)이 있고, 그 주성분인 콜라겐 섬유가 그물(reticular network)처럼 얽혀 있어요. 이 그물의 구조가 세포 이동, 분열, 분화를 물리적으로 제어해요.

🔬 콜라겐이란?

직경 ~50 nm, 길이 수십 µm의 단백질 섬유. 체내 가장 흔한 구조 단백질 (단백질의 ~30%). 실처럼 구불구불하고, 당기면 강해지고 밀면 휜다.

🧬 세포는 뭘 하나?

섬유모세포(fibroblast)는 LOX 효소로 콜라겐을 합성하고, 내부 액틴-미오신 모터로 ECM을 수축시킨다. 견인력 ~1–10 nN.

🌐 구조는 어디서 오나?

세포가 구조를 "그리는" 게 아니다. 수축력 + 비선형 역학 + 재형성이 결합해서 구조가 자발적으로 출현(emergence)한다.

핵심 실험 (Stopak & Harris, 1982)
닭 심장 조각(explant) 두 개를 콜라겐 젤 위에 올렸더니 — 단일 explant 주변엔 방사형 별(aster)이, 두 explant 사이엔 정렬된 교량(bridge)이 자발적으로 나타났다. 세포가 설계도를 갖고 있었던 게 아니라, 수축력이 ECM을 물리 법칙에 따라 자기조직화시킨 것.

Stopak-Harris 현상 — 브릿지 정렬 (시뮬레이션 재현)

우리 모델(n=4 seeds, mean ± SEM). 파란 선: 두 세포를 잇는 축 방향 정렬. 회색 선: 수직 방향 (등방성 기준선 0.333). 거리 전 범위에서 축 방향이 유의미하게 높다.

§ 2 · 핵심 물리

콜라겐 섬유의 비선형 역학

일반 스프링(후크 법칙)은 당기든 밀든 힘이 대칭이에요. 콜라겐은 그렇지 않아요. 두 가지 비선형성이 자기조직화를 가능하게 해요.

인터랙티브 데모 — 섬유를 직접 당겨보세요

0 %

① 좌굴 (Buckling)

섬유는 실처럼 생겼어요. 당기면 팽팽해지지만 밀면 즉시 휘어서 힘을 거의 전달하지 못해요. 압축 강성이 장력 강성의 ~5%에 불과.

// 압축 (strain < 0)
F = k × buckle_ratio × strain
// buckle_ratio ≈ 0.05 (장력 대비 5%)

왜 중요한가? 세포가 사방으로 당기면, 당기는 방향(방사) 섬유만 하중을 받고 수직 방향 섬유는 좌굴로 기여 못 해요. 힘이 특정 방향에 집중 → 정렬 패턴 출현.

② 변형경화 (Strain-stiffening)

콜라겐 섬유는 구불구불한 형태를 가져서, 처음엔 쉽게 늘어나다가 많이 늘어날수록 급격히 뻣뻣해져요. 섬유가 쭉 펴지는 시점에 강성이 수~수십 배 증가.

// 장력 (strain > 0)
F = k × strain × (1 + α × strain)
// α ≈ 8 (변형경화 계수)

왜 중요한가? 세포 근처 고변형 섬유가 더 강해지면서 힘 전달이 장거리로 집중돼요. 실험에서도 확인된 long-range force transmission.

비선형성의 기여 (정량)
bridge 방향 신호 (axis − perp alignment):
완전 선형 → 0.081 · 좌굴만 → 0.156 · 전체 비선형 → 0.160
비선형성이 신호를 ~2배 강화. 좌굴이 지배적 기여자, 변형경화는 부가적.

① 네트워크 성장 — Mikado 모델

실제 콜라겐 섬유화(fibrillogenesis)를 4단계로 모사해요:

Nucleation: 랜덤 위치에 씨앗점 생성
Elongation: 방향성 있는 성장 (persistence length로 구불구불함 제어)
Branching: 확률적 분기점 생성 (branch_prob)
Crosslinking: 근접 섬유 끝 연결 (crosslink_dist)

NetworkParams(
  n_cells=24,
  seg_length=3.0, // µm/segment
  branch_prob=0.07,
  crosslink_dist=4.5
)

결과: 3방향 분기점(coordination ≈ 3)이 지배적인 구불구불한 그물. 이게 실제 콜라겐/FRC 네트워크 형태와 일치해요.

② 역학 평형 — FIRE 알고리즘

각 마디에 걸리는 힘(섬유 장력 + 굽힘 저항 + 세포 견인력)을 계산하고, 모든 마디가 힘 균형에 도달하는 위치를 찾아요.

FIRE (Fast Inertial Relaxation Engine): 가상 관성을 이용해 에너지 최솟값으로 빠르게 수렴. 일반 gradient descent보다 ~5–10배 빠름.

// 수렴 조건
while max|F| > ftol:
  F = Σ(fiber) + Σ(bend)
    + F_traction
  v = FIRE_update(v, F)
  x += v × dt
// max|F| → 9.9×10⁻³ 수렴

③ 소성 재형성 — Percentile Remodeling

실제 세포는 장력을 받는 섬유를 강화(LOX 효소)하고, 느슨한 섬유를 분해(MMP 효소)해요. 이를 percentile-based 규칙으로 구현해요.

// 상위 15% 장력 → 강화
if strain > P85: k *= reinforce

// 하위 15% 장력 → 제거
if strain < P15: remove_fiber()

소성 기억(Plastic Memory): 재형성 후 세포를 제거해도 강화된 경로가 남아요.

×400
세포 제거 후 잔류 내부응력
소성 4250 vs 탄성 11

인터랙티브 데모 — 단일 세포 수축 & Aster 형성

색상: 파란색 = 장력 (하중 전달), 회색 = 좌굴 (기여 없음), 주황 = 세포. 좌굴 비대칭성 때문에 방사 방향 섬유만 강화되어 별(aster) 패턴이 나타남.

SI 단위 보정 (order-of-magnitude)
기준: 측정된 세포 견인력 ~1 nN, 세포 간격 ~100 µm
→ 길이 1 단위 = 1 µm · 힘 1 단위 = 0.156 nN · 응력 = 156 Pa · 네트워크 탄성계수 G ≈ 0.8 Pa (희석 콜라겐 젤 범위)

def ring_centers(n, R):
  return [(R·cos(2πi/n),
           R·sin(2πi/n))
          for i in range(n)]
