ECM 연구 업그레이드 — 인터랙티브

네 가지 업그레이드를 브라우저에서 직접 돌려볼 수 있게 만들었습니다. 슬라이더를 움직이고, 토글을 켜고, 시뮬레이션을 재생해 보세요 — 모두 이 페이지 안에서 실시간 계산됩니다.

A

비선형 섬유 역학 + floppy-mode 솔버

force-extension 라이브 계산 · FIRE vs Newton 수렴(실측 데이터)

왼쪽: 콜라겐 섬유의 비대칭 좌굴 + 변형 경화 구성식을 슬라이더로 직접 계산합니다(압축은 약하게 좌굴, 인장은 경화). 오른쪽: 실제 측정한 전단 스윕 — FIRE는 선형 영역 너머에서 힘 평형에 실패하지만, Newton 솔버는 강성 전이 γ_c까지 도달합니다. γ 슬라이더로 두 솔버의 잔차를 비교해 보세요.

섬유 1개의 장력 vs 변형 — 0 근처에서 꺾임(좌굴), 인장에서 위로 휨(경화)
B

분포 적합도 — KS / EMD (디지타이즈 데이터 대비)

binned KS · Wasserstein-1 · 실시간 계산

모델 pore 분포(초록)를 디지타이즈된 참조 히스토그램(회색 막대)에 맞춰 보세요. 중앙값을 맞춰도(스케일 일치) 모양이 다르면 KS가 잡아냅니다. 슬라이더로 중앙값과 퍼짐을 바꾸면 D·p·EMD가 실시간으로 갱신됩니다. (참고: 로그정규로는 데이터에 잘 맞출 수 있지만, 실제 ECM 모델의 emergent 분포는 이 참조와 D=0.087로 구분됩니다 — 이게 연구 결과의 핵심: 중앙값 일치 ≠ 분포 일치.)

초록 곡선=모델 밀도 · 회색 막대=디지타이즈 참조(collagen_pore_um.csv, 453 pores)
C

베이즈 추론 — 라이브 사후분포

실측 forward 응답 · 관측값+노이즈 → 사후분포

실제 forward 모델로 계산한 bridge 신호 vs buckle_ratio 곡선(왼쪽)을 씁니다. 관측값과 관측 노이즈를 정하면, 오른쪽에 buckle_ratio의 사후분포가 실시간으로 계산됩니다(가능도 × 균일 사전). 노이즈를 키우면 사후가 넓어지는 걸 보세요.

실측 forward: bridge 신호는 buckle_ratio가 커질수록 감소(단조)
D

세포 응집 — 라이브 시뮬레이션

durotaxis ± chemotaxis · 실시간 ABM

세포(주황)가 자기가 만든 강성장(파랑)을 따라 이동합니다. chemotaxis를 끄면 각자 자기 강성만 따라가 흩어지고, 켜면 서로를 향한 화학 신호로 모입니다. 재생하고 토글을 바꿔 보세요 — 평균 세포간 거리가 실시간으로 표시됩니다.

실제 3D 모델 결과와 동일한 경향: durotaxis만 → 분산(거리 증가), +chemotaxis → 응집(거리 감소). 강화 네트워크(파랑 흔적)는 양쪽 다 생깁니다.
전부 이 페이지 안에서 실시간 계산됩니다(외부 서버·인터넷 불필요). 비인터랙티브 요약본은 research_upgrades.html, 전체 서술은 RESEARCH_UPGRADES.md.
